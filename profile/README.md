# Начинаем вайбучиться

Здесь живут короткие, проверяемые и постепенно улучшаемые курсы для обучения через
IDE и AI-агента. Идея проста: не бесконечно смотреть туториалы и не угадывать, что
считается хорошим решением, а проходить законченные практические карточки с понятной
проверкой.

## Зачем

Самообучение легко превращается в tutorial hell: материал есть, но нет обратной
связи по пониманию, качеству решения и следующему маленькому шагу. Платные
практикумы часто закрывают эту проблему, но не всегда дают нужную персонализацию.

LLM здесь полезна не как генератор готового кода, а как автор и преподаватель:

- собирает маршрут под начальные знания и целевой стек;
- объясняет модель работы технологии и границы аналогий с привычным стеком;
- проверяет реализацию и объяснение как преподаватель;
- выдаёт ровно столько помощи, сколько нужно, чтобы закончить текущую сессию.

## Как устроен курс

Каждая карточка рассчитана на 30–60 минут и завершается зелёным результатом:

- quiz, наблюдение поведения, поиск ошибки, completion/refactor или маленькая
  реализация;
- локальная автоматическая проверка воспроизводимых фактов;
- отдельный agent review для объяснения, смысловых критериев и best practices;
- progressive hints без открытых рядом готовых ответов;
- финальный проект, который объединяет изученные части.

Курс живёт в Git-репозитории и проходится из IDE: подсветка, Markdown preview,
тесты и dev server остаются привычными инструментами разработчика.

## Для авторов и агентов

**До создания нового курса или изменения его учебного формата обязательно
прочитайте [course-template](https://github.com/ai-supported-education/course-template):
[AGENTS.md](https://github.com/ai-supported-education/course-template/blob/master/AGENTS.md),
[руководство автора](https://github.com/ai-supported-education/course-template/blob/master/docs/authoring-a-course.md)
и [стандарт материала](https://github.com/ai-supported-education/course-template/blob/master/curriculum/authoring-standard.md).**

Репозиторий-шаблон содержит stack-neutral runner, контракт короткой сессии,
разделение learner-facing материалов и `course-support`, а также профиль для
React-курсов. FSD — только часть React-профиля, не правило всех будущих курсов.

## Курсы

### В разработке

- [Переход с Vue 3 на React](https://github.com/ai-supported-education/vue2react) —
  путь от ментальной модели React и компонентов до инфраструктуры, CI/CD и
  итогового operations dashboard.

### В планах

- переходный backend-курс с Node.js на Java-стек;
- алгоритмы для собеседований;
- сети;
- беспроводные сети на ESP: Wi-Fi, Bluetooth, BLE, ESP-NOW, физика и стандарты;
- беспроводные сети через SDR: analog, LTE, 3G, GSM и mesh;
- высшая математика с программированием и итоговым физическим движком;
- self-hosted обучающая платформа либо аддон для VS Code / JetBrains IDE.
